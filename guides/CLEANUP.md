# Практика безопасной уборки

Условная инструкция для запрошенной/необходимой уборки. Единственное требование: [CLEANUP-001](../core/PROCESS.md#безопасная-уборка-репозитория-после-разработки). Эти примеры не добавляют новый gate.

- Составьте таблицу «путь → владелец → зависимость → как восстановить». Неизвестное оставьте на месте.
- Типичные кандидаты: собственные caches и воспроизводимые generated outputs. Перед удалением подтвердите источник генерации и отсутствие уникального результата.
- Проверьте ссылки, текущие процессы/ветки и установленные плагины. `.gitignore` — подсказка, не доказательство.
- Сохраните точку восстановления и проверяемый список изменений. После уборки сравните inventory и запустите затронутые проверки.

Если удалять нечего, достаточно записи «безопасных кандидатов нет». Не нужна таблица из четырнадцати обязательных пунктов для каждой правки.
