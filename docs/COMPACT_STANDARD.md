## Changes in applicability

- Light chooses core plus component/runtime minimum and task overlays. Git/identity/regression/Evidence/baseline duties remain in the core; their detailed definitions remain addressable stable sections, rather than ten separate default groups.
- Standard/Critical and feature/distribution/version dependency routes retain their existing additional groups. Validation/Release still selects the single gate. Explicit reference retains Reference Audit without granting implementation.
- Inert text needs reviewed retrieved identity/scope, not an executable scan or unavailable source commit. Local executable packages require full inventory/scan/protected admission. Closed remote services require observed provider/endpoint/interface/permissions/data scope/capability checks, not unavailable server bytes. Mixed extensions use the applicable contract for each part; inert permission never authorizes execution.
- Retrospective becomes proportional SHOULD after new knowledge; cleanup safety remains mandatory where cleanup occurs, with examples outside default reading. Detailed experimental agent evaluation is optional for an actual effectiveness investigation, not every plugin release.

These are intentional adoption changes, so VERSION is 11.0.0 candidate rather than a patch to 10.0.2. Freeze adopted baselines until explicit migration. No normative Adobe/runtime requirement is relaxed. A local adapter that supports only immutable source commits may remain stricter than the general executable provenance contract; unsupported inputs are BLOCKED for that adapter, not silently accepted.

## Optional package and compatibility

`packages/agent-evaluation/` owns the observer implementation, checker, schemas, extension fixtures and protocol. Old script/import paths are thin compatibility loaders, preserving behavior and nonzero failures. Schema/catalog consumers must use the package paths. Do not copy only old loaders into a product expecting them to work; select the whole optional module and dependencies if needed.

Acting-agent snapshots exclude the entire package; new paths cannot expose held-out answers or observer procedure. Historical experiment records remain bound to old source/fixture/configuration bytes; no record is upgraded or reassigned. Repository self-test continues to check optional tool contracts; running that self-test does not oblige a product to run the experiment.
