# Configure independent GitHub Evidence verification

This setup is **not active until a repository administrator configures it**. The workflow is staged in the PR; after an approved merge to the protected default branch, it can be dispatched manually. It does not replace actual AE/iPhone testing.

1. In each repository create GitHub Actions environment `reference-evidence`. Restrict deployment to the protected `main` branch and require an independent reviewer where the GitHub plan supports it. Protect `main` and `.github/workflows/trusted-reference-evidence.yml` with required review/CODEOWNERS as applicable. Do not assume those settings are active until verified.
2. Provision environment **secret** `TRUSTED_WITNESS_JSON` containing a manifest generated by a separate authorized observer, NOT the implementation agent or candidate PR. It must include the pinned reference digest, candidate revision, capture IDs, capture digests, runner identity, run IDs, observation times, authority and approval.
3. Provision environment **variable** `TRUSTED_WITNESS_SHA256`: SHA-256 of the canonical JSON representation (`json.dumps(obj, sort_keys=True, separators=(',', ':'), ensure_ascii=False).encode()`). Set this independently of candidate input. Keep both values inaccessible to PR authors.
4. From the default branch Actions tab, manually run **Trusted Reference Evidence Review** with exact 40-character candidate commit SHA and a safe relative ledger path. The job checks out the verifier from `main`, the candidate separately, and compares to the independently pinned witness.
5. Review the actual workflow run, witness creation provenance and real host/device evidence. A green comparison verifies consistency with the protected witness, not authenticity of physical execution by itself.

**Not configured by this PR:** repository branch protection, environment protection, reviewer membership, trusted capture producer, external evidence custody and AE/iPhone execution. No automatic PASS or release authorization should be claimed until those are independently verified. Do not put witness secrets in PR files, logs or fixtures.
