## Adoption and compatibility

Keep an existing accepted standard version/commit until consciously adopting this correction. Pin the immutable release commit and verify downloaded archives against SHA256SUMS.txt and release-evidence.json.

Run `node starter-kit/scripts/self-test.mjs --dry-run` from the complete standard repository. It needs Node.js 22+, Python 3.11+, zsh for POSIX checks and a C++17 compiler for native examples. Windows CI checks PowerShell contracts separately. A scripts-only product copy cannot run the repository self-test; copy full tool dependencies and applicable schemas/fixtures/templates, then run the product's own selected checks.

**Witness migration:** each capture requires `owner_sha256 = SHA-256(canonical(obligation.owner))`. Canonical JSON is UTF-8, sorted keys, compact separators, ensure_ascii=False, with no non-finite numbers. The complete owner includes path, revision and source-file hash. Regenerate the protected manifest, independently review the association and obtain a new external pin. Do not silently add a hash to an old approved manifest or relabel historical Evidence. Source commit S and Evidence commit E stay separate as introduced in 10.0.1.

This is a correction to existing owner/Evidence binding and the existing validation/lifecycle/reading contracts, not a new normative AE rule or a broader mandatory process. The capture schema adds a required field intentionally: accepting an old unbound manifest would retain the security defect. Frozen project baselines and old tools/manifests remain historical until explicit migration. MFR/SmartFX, memory, threads, alpha/HDR and product runtime acceptance requirements remain unchanged.

## Operational and pilot limits

An earlier separate JSX/AEP project was created/rendered in AE 25.6; that bounded observation is not exact-candidate validation of these tools or evidence of agent-layer benefit. The next experiment must freeze tasks, baseline, skill/policy/configuration and observer checks, compare repeated skill/no-skill runs and verify actual AE output. No expansion of rules is justified by this release.
