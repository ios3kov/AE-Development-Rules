# AE Development Rules 6.2.0

2026-10-02 · Minor release

Уточняет существующий COMPAT-001 и добавляет шаблон удалённой проверки. Установка всех целевых AE на машине разработчика не обязательна. Interfaces/schema, Compatibility Status и обязательный runtime Evidence для официально поддерживаемых версий сохраняются.

## Что изменилось

- [Engineering §21](../../core/ENGINEERING.md#протокол-проверки-без-локальной-установки-всех-ae): documented minimum AE отдельно от SDK, полнота inventory включая wrappers/conditional/generated/dependency paths и отдельный audit JSX/CEP/UXP.
- Проверка exact distributed artifact после post-processing; baseline SDK probe и missing-capability tests при применимости. Lexical collection COMPLETE, compile/mock PASS не являются runtime compatibility.
- Выбор минимальной/текущей целевых AE и дополнительных version/build boundaries по риску. Endpoint tests не подтверждают промежуточные версии или будущий «AE X+».
- [Remote packet](../../starter-kit/templates/REMOTE_COMPATIBILITY_CHECK.md): artifact hash/manifest, owned fixture, install/rollback, full AE build/OS/architecture и фактически loaded identity, steps/expected/actual results/Evidence. Подготовка пакета сама не разрешает отправку, установку или restart чужой AE.
- Согласованы API audit, matrix, checklist и registry. Материальные неизвестные остаются UNKNOWN; unavailable mandatory runtime checks — BLOCKED / NOT RUN. VERIFIED требует фактического запуска нужной AE с matching identity в заявленном scope.
- Сохраняется ранее слитый [AE render-validation know-how](../AE_ENGINEERING_KNOWHOW.md). Его исторические наблюдения не подтверждают новый artifact и не являются универсальными API guarantees.

## Начало работы и переход

Начните с [AI_ENTRYPOINT.md](../../AI_ENTRYPOINT.md). Явно передайте новой/текущей сессии ИИ новый baseline; автоматического обновления ранее принятых правил нет. Existing project baseline остаётся до осознанного adoption по §34; прежние Evidence не переобозначаются.

Используйте [API audit](../../starter-kit/templates/API_COMPATIBILITY_AUDIT.md) и [matrix](../../starter-kit/templates/COMPATIBILITY_MATRIX.md); для недоступной локально AE подготовьте remote packet. Можно встроить формы в существующие records, без дубликатов и искусственного расширения scope. Реальный remote run выполняется только при наличии разрешения и нужного host.

Schema manifest 3, project-record 1 и artifact 2, platform certificate/service policy и release documentation handoff сохраняются. Данный релиз добавляет/уточняет workflow, не реализует универсальный emulator AE или автоматическое определение всех minimum versions.

## Evidence и откат

Exact released commit, CI для PR/main и hashes архивов фиксируются после фактических проверок в GitHub Release / release-evidence.json. Реальные model, remote product/AE compatibility tests **NOT RUN** для этого выпуска правил.

Main перед релизом сохранён в `backup/main-before-v6-2-release-2026-10-02-449b7bb`, полный Git bundle сохранён локально. Он включает документацию, слитую после 6.1.0. Опубликованный v6.1.0 и прежние tags/releases/artifacts сохраняются отдельно; теги не перемещаются.
