## Adoption

Run `node starter-kit/scripts/self-test.mjs --dry-run` from the full standard repository. Node.js 22+, Python 3.11+, zsh for POSIX checks and a C++17 compiler for native examples are required. The self-test checks root canonical documents, profiles, manifest, registry, fixtures and workflows; copying only scripts is insufficient. Copy complete script dependencies plus applicable schemas/fixtures/templates into a product and verify the product's selected checks separately.

Reference dispatch now requires `candidate_sha=S`, `evidence_sha=E` and `ledger_path` relative to E. Commit the source first, capture and review Evidence for S, then store reports in E (which may be a later commit or separate branch in the same repository). Do not rewrite report revisions to E. Owner paths are relative to S; artifact paths are relative to E. New optional local CLI flag `--candidate-root` selects S; omitting it retains combined-root local behavior. See [setup](../SETUP_TRUSTED_REFERENCE_EVIDENCE.md). Skills mode retains its existing source/policy/candidate inputs and needs no Evidence SHA.

No normative rule or schema changes. The additional reference workflow input repairs the previously unusable self-referential storage path. Package reading and task resource checks enforce existing completeness/exclusivity requirements. Existing AE MFR/SmartFX, alpha/HDR, memory/thread and runtime requirements remain in force.
