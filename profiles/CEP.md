# CEP Profile

Этот файл — навигатор, а не дубликат нормативных правил.

Для CEP применяются:

- [Process Core](../core/PROCESS.md);
- [Engineering Core](../core/ENGINEERING.md), включая §21 Technology Lifecycle Status;
- [Tools / Panels Runtime Profile](TOOLS.md);
- [Release / Distribution Profile](RELEASE.md) для delivery gates.

CEP на baseline 2026-10-01 имеет Technology Lifecycle: **DEPRECATED** для новой долгоживущей архитектуры согласно Adobe roadmap. Existing maintenance допускается в документированном scope, но новые production decisions MUST иметь migration/exit plan. Актуальность статуса проверяется по [SOURCES.md](../SOURCES.md).
